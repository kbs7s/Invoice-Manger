      تجهيز Firebase أول مرة (5 دقائق)
      1. افتح console.firebase.google.com وأنشئ مشروعاً جديداً (مجاني، خطة Spark).
      2. Authentication ← Get started ← فعّل Email/Password.
      3. Firestore Database ← Create database ← اختر أقرب منطقة ← Production mode.
      4. في Firestore ← Rules الصق هذه القواعد واضغط Publish: 
        rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /users/{uid}/{doc=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}
      5. Project settings ← Your apps ← أضف Web app وانسخ apiKey وprojectId للبرنامج.
      6. بعد ما تنشئ حسابك من البرنامج: Authentication ← Settings ← User actions ← ألغِ Enable create (sign-up) حتى محد غيرك يقدر يسجّل.
