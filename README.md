# مدير الفواتير والوصولات (Invoice Manager)

برنامج محلي بصيغة HTML لإصدار فواتير المبيعات ووصولات القبض بتصاميم ومقاسات مختلفة (A4 و A5).
يعمل بدون إنترنت، ويحفظ كل شيء كملفات داخل مجلد تختاره على جهازك.

## التشغيل

1. افتح `index.html` باستخدام **Google Chrome** أو **Microsoft Edge** (المتصفحات الأخرى لا تدعم الحفظ داخل مجلد).
2. أول مرة، اضغط **اختيار مجلد العمل** واختر مجلداً فارغاً، مثلاً `Documents/الفواتير`.
3. في المرات التالية، اضغط **متابعة العمل**، لأن المتصفح يطلب تأكيد الإذن في كل مرة.

لنقل العمل إلى جهاز آخر: انسخ مجلد البرنامج ومجلد العمل، ثم اختر نفس مجلد العمل على الجهاز الجديد. الترقيم يكمل من حيث توقف.

## ترتيب مجلد العمل

```
workspace.json                         علامة المجلد
settings/settings.json                 بيانات الجهة، الشعار، العملة، المقاس، بادئات الترقيم
settings/counters.json                 آخر رقم صادر لكل نوع مستند
templates/<id>.json                    القوالب المضافة
documents/<type>/<year>/<type>-00001.json   المستندات الصادرة
```

## ملفات البرنامج

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة |
| `app/storage.js` | الوصول للمجلد (File System Access API)، وحفظ إذن المجلد في IndexedDB |
| `app/store.js` | الإعدادات، الترقيم، المستندات، القوالب، النسخ الاحتياطي |
| `app/app.js` | منطق الواجهة |
| `app/render.js` | تحويل المستند + القالب إلى صفحات، التفقيط، الحسابات، الطباعة |
| `app/sheet.css` | الورقة المشتركة (A4 / A5) وقواعد الطباعة |
| `app/templates/*.js` | القوالب: `classic` (الكلاسيكي)، `modern-angle` (الحديث المائل)، `modern-sidebar` (الشريط الجانبي) |
| `app/fonts/` | خطوط Cairo و Readex Pro محلية (رخصة OFL) حتى يعمل بدون إنترنت |
| `app/styles.css` | تنسيق واجهة البرنامج |

## القوالب والمقاسات

| | A4 | A5 |
|---|---|---|
| فاتورة مبيعات | صفحة كاملة عمودية | نفس التصميم مصغّر على A5 عمودي |
| وصل قبض | وصلين بالورقة (أصل + نسخة) مع خط قص | وصل واحد على A5 أفقي |

كل قالب يدعم: نموذج فارغ للكتابة اليدوية، علامة مائية من الشعار، وألوان قابلة للتعديل تُحفظ في الإعدادات.

## خطة العمل

1. ✅ أساس البرنامج والحفظ على القرص
2. ✅ تحويل التصاميم الحالية إلى قوالب (A4 / A5)، بدون أسماء المكاتب
3. ⏳ شاشة الإصدار والمعاينة والطباعة والأرشيف
4. ⏳ إضافة قوالب جديدة واستيرادها
