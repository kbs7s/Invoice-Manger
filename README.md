# مدير الفواتير والوصولات (Invoice Manager)

برنامج محلي بصيغة HTML لإصدار فواتير المبيعات ووصولات القبض بتصاميم ومقاسات مختلفة (A4 و A5).
يعمل بدون إنترنت، ويحفظ كل شيء كملفات داخل مجلد تختاره على جهازك.

## التشغيل

1. افتح `index.html` باستخدام **Google Chrome** أو **Microsoft Edge** (المتصفحات الأخرى لا تدعم الحفظ داخل مجلد).
2. أول مرة، اضغط **اختيار مجلد العمل** واختر مجلداً فارغاً، مثلاً `Documents/الفواتير`.
3. في المرات التالية، اضغط **متابعة العمل**، لأن المتصفح يطلب تأكيد الإذن في كل مرة.

لنقل العمل إلى جهاز آخر: انسخ مجلد البرنامج ومجلد العمل، ثم اختر نفس مجلد العمل على الجهاز الجديد. الترقيم يكمل من حيث توقف.

## الاستخدام اليومي

- **إصدار مستند:** اختر النوع والقالب والمقاس، عبّئ البيانات، والمعاينة تتحدث مباشرة. الرقم يُعطى تلقائياً عند الحفظ (أو اكتب رقماً يدوياً).
- اختصارات: `Ctrl+S` حفظ، `Ctrl+P` طباعة، و `Enter` في آخر سطر مواد يضيف سطراً جديداً.
- البرنامج يتذكر طريقة الدفع والشروط واسم المحاسب من آخر مستند لكل نوع.
- **لوحة التحكم:** المبيعات والمقبوض ونسبة التحصيل (هذا الشهر / هذه السنة / الكل)، آخر المستندات، وأكثر الزبائن ديناً.
- **الأرشيف:** بحث بالاسم أو الرقم أو التاريخ، فلترة حسب الحالة (مدفوعة / جزئية / آجل)، ومنه: فتح للتعديل، طباعة، تكرار كمستند جديد، حذف.
- **العملاء:** يُجمعون تلقائياً من المستندات. لكل زبون: المشتريات، المقبوض (الواصل + وصولات القبض)، والمتبقي عليه. زر «وصل قبض» يعبّي اسمه والمبلغ المتبقي.
- **الوضع الليلي:** زر 🌙 أعلى الشاشة، ويتذكره البرنامج.

## الحفظ على GitHub

اختياري. من **الإعدادات ← الحفظ على GitHub** تربط البرنامج بمستودع GitHub **خاص** للبيانات (منفصل عن مستودع البرنامج)، فيُرفع كل حفظ تلقائياً بنفس ترتيب ملفات المجلد:
بيانات الجهة، القالب المختار وألوانه، الترقيم، وكل الفواتير والوصولات.

- المجلد يبقى هو الأساس ويعمل بدون إنترنت. التغييرات تنتظر وتُرفع عند رجوع الاتصال.
- على جهاز لا يدعم المجلدات (الهاتف مثلاً) اختر **الحفظ على GitHub بدون مجلد** من شاشة البداية.
- **تنزيل من GitHub إلى المجلد** يجلب ما صدر من الأجهزة الأخرى.

التجهيز أول مرة:

1. أنشئ مستودعاً خاصاً (Private)، مثلاً `invoice-data`.
2. أنشئ Fine-grained token من `github.com/settings/personal-access-tokens/new`: صلاحية على مستودع البيانات فقط، و **Contents: Read and write**.
3. الصق الرمز واسم المستودع (`اسمك/invoice-data`) واضغط «ربط بـ GitHub».

الرمز يُحفظ في المتصفح فقط ولا يُكتب في الكود. البرنامج يرفض الربط إذا كان مستودع البيانات عاماً.

## النشر على GitHub Pages

الملف `.github/workflows/pages.yml` ينشر البرنامج عند كل دمج في `main`، فيفتح من رابط بدل الملف.
فعّله مرة واحدة من Settings ← Pages ← Source: **GitHub Actions**.
(GitHub Pages للمستودع الخاص يحتاج اشتراك GitHub Pro، أو اجعل المستودع عاماً. البيانات لا تكون بالمستودع، فهي في مجلد العمل على جهازك.)

## ترتيب مجلد العمل

```
workspace.json                         علامة المجلد
settings/settings.json                 بيانات الجهة، الشعار، العملة، المقاس، بادئات الترقيم
settings/counters.json                 آخر رقم صادر لكل نوع مستند
templates/<id>.json                    القوالب المضافة
documents/<type>/<year>/<type>-00001.json   المستندات الصادرة
```

## ملفات البرنامج

| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة |
| `app/storage.js` | الوصول للمجلد (File System Access API)، وحفظ إذن المجلد في IndexedDB |
| `app/store.js` | الإعدادات، الترقيم، المستندات، القوالب، النسخ الاحتياطي |
| `app/cloud.js` | الحفظ في مستودع GitHub خاص عبر GitHub API |
| `app/app.js` | منطق الواجهة: الأرشيف، القوالب، الإعدادات |
| `app/issue.js` | شاشة الإصدار: نموذج الإدخال، المعاينة المباشرة، الحفظ والطباعة |
| `app/render.js` | تحويل المستند + القالب إلى صفحات، التفقيط، الحسابات، الطباعة |
| `app/sheet.css` | الورقة المشتركة (A4 / A5) وقواعد الطباعة |
| `app/templates/*.js` | القوالب الأساسية: `classic`، `modern-angle`، `modern-sidebar`، ومن ملفات الإكسل: `banner` (الترويسة بالشعار)، `bilingual` (ثنائي اللغة)، `boxed` (المربعات) |
| `template-examples/` | صيغة القوالب المستوردة (JSON) مع مثال جاهز للاستيراد |
| `app/fonts/` | خطوط Cairo و Readex Pro محلية (رخصة OFL) حتى يعمل بدون إنترنت |
| `app/styles.css` | تنسيق واجهة البرنامج |

## القوالب والمقاسات

| | A4 | A5 |
|---|---|---|
| فاتورة مبيعات | صفحة كاملة عمودية | نفس التصميم مصغّر على A5 عمودي |
| وصل قبض | وصلين بالورقة (أصل + نسخة) مع خط قص | وصل واحد على A5 أفقي |

كل قالب يدعم: نموذج فارغ للكتابة اليدوية، علامة مائية من الشعار، وألوان قابلة للتعديل تُحفظ في الإعدادات.

## خطة العمل

1. ✅ أساس البرنامج والحفظ على القرص
2. ✅ تحويل التصاميم الحالية إلى قوالب (A4 / A5)، بدون أسماء المكاتب
3. ✅ شاشة الإصدار والمعاينة والطباعة والأرشيف
4. ✅ إضافة قوالب جديدة واستيرادها (ملف JSON من تبويب القوالب، يُحفظ في `templates/` بمجلد العمل)
